# Data Science — an applied course

A course for those who want to solve business problems with data: from framing a hypothesis to shipping a model and monitoring it. No filler, concrete artifacts per lesson.

## Who this is for

- Analysts who want to grow into ML/DS
- Developers transitioning to DS
- ML engineers who lack the product side (metrics, A/B, business)

## What you will leave with

- 4 portfolio projects on GitHub: EDA, production ML, A/B test, dashboard
- Templates: model spec, project folder structure, A/B report, ML canvas
- The skill of taking a task from "we have data" all the way to "shipped solution with metrics"

## How to take it

1. Do the tasks by hand, do not copy code.
2. Each lesson → a commit to your own repo with README and conclusions.
3. After each block — a mini-retrospective: what I learned, where I'm stuck.
4. Publish capstones as separate repos — they become your portfolio.

## Prerequisites

- Basic Python (functions, classes, list/dict)
- High-school math, ideally — [math-for-ml](../math-for-ml/README.md)
- Git at the clone/commit/push level
