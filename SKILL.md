# How to use this repository as a "skill"

This file describes how to consume the roadmap as a single trackable skill — useful if you drive your learning with an AI assistant (Claude, ChatGPT, Cursor) or with any "skill" framework that takes Markdown plans.

## High-level skill

> **Goal:** become an ML engineer who can ship — from training a model to deploying it to production, with monitoring and evals.

## Tracks

Pick one and stick with it for at least 6 weeks.

- **Track A — Applied ML engineer.** [data-science/](./data-science/README.md) → [neural-networks/](./neural-networks/README.md) → [llm-engineering/](./llm-engineering/README.md) → [practice-labs/](./practice-labs/README.md). 6–9 months.
- **Track B — LLM / GenAI engineer.** [math-for-ml/](./math-for-ml/README.md) (light) → [neural-networks/](./neural-networks/README.md) (blocks 1–3) → [llm-engineering/](./llm-engineering/README.md) (full). 4–6 months.
- **Track C — Computer Vision engineer.** [math-for-ml/](./math-for-ml/README.md) → [neural-networks/](./neural-networks/README.md) → [computer-vision/](./computer-vision/README.md). 6–9 months.
- **Track D — Research-leaning.** [math-for-ml/](./math-for-ml/README.md) (full) → [neural-networks/](./neural-networks/README.md) (full) → papers + reimplementations. 9–12 months.

## Definition of done for the whole skill

- A portfolio with 3+ end-to-end projects on GitHub (model in production, RAG, A/B or eval pipeline).
- You can pass an interview at the matching level (see [interview-prep/](./interview-prep/README.md)).
- You can give a 20-minute talk on at least one applied topic without slides.
- You can read a recent ML paper and explain the contribution in three sentences.

## Weekly cadence

1. **Mon–Tue:** new lesson — theory + code line by line.
2. **Wed–Thu:** rewrite the code without peeking + exercises.
3. **Fri:** one practice lab from [practice-labs/](./practice-labs/README.md).
4. **Sat:** weekly retrospective — what you learned, where you wobbled, what to fix next week.
5. **Sun:** rest. Genuinely rest. No "I will just read one paper".

## Anti-patterns

- Reading without doing.
- Watching YouTube instead of opening an IDE.
- Switching tracks every two weeks.
- Tutorial hell: 50 hours of tutorials, 0 hours of your own code.
- Tracking hours instead of artifacts. Three real projects beat 1000 hours of "studying".
